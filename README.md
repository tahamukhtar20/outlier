# Outlier

The website of a fictional product studio, built around a team builder: pick what you are building, the features, the deadline and where you are now, and it puts together the specialists you would need, a sprint plan and a cost range. New specialists fly in from the option that brought them; the schedule and numbers update as you go.

Live at [outlier.tahamukhtar.com](https://outlier.tahamukhtar.com).

This is an anonymised client project. The original 2023 build was a one-page site for a development studio, made from a design file with stock images. This version keeps its look (dark, cyan to purple) and its idea, replaces every image with illustrations generated in code, and adds the team builder and an opening animation.

## Team builder

`src/lib/builder.ts` is a set of fixed rules, so the same choices always give the same plan and every number can be explained:

- Each product and feature adds engineer-weeks to tracks (web, backend, mobile, game, art, ML); the stage scales them.
- Each track is staffed in half-time steps from its effort and the build weeks.
- Every team has a product lead, a designer and QA; real-time features, live products and large plans add a platform engineer.
- Cost is each role's weekly rate times its time on the project, plus 5% coordination overhead per person beyond eight, shown as a range.
- When a deadline needs more than twelve people, it suggests the shortest schedule that fits one team.

The site lists the reasons for the current plan under "How this is worked out".

## Illustrations

Everything visual is generated by the scripts in `art/`:

- `hand.mjs`: a mechanical hand built from parameters (finger segments, curls, joints, glowing seams), posed open, pointing and reaching.
- `pieces.mjs`: butterfly, AI head with circuit traces, lightning bolt, gears, orbit rings.
- `icons.mjs`: a duotone icon set, the spinning stamp and the logo.
- `avatars.mjs`: ten illustrated team portraits.
- `scene.mjs`: the hero scene and its opening animation (CSS keyframes, played once per visit, skipped with reduced motion).

`npm run art` writes `src/art.gen.ts` for the site, plus a contact sheet and a standalone intro page in `art/out/`.

## Development

```bash
npm install
npm test            # builder rules
npm run dev         # http://localhost:4480
npm run build       # regenerate art, type-check, build to dist/
npx wrangler deploy
```
